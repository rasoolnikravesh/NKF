# NKF.Domain.Tests

Unit tests for NKF Domain primitives.

## Features

- Tests for Entity, AggregateRoot, ValueObject
- Domain event handling verification
- Duplicate/Deep clone testing

## Install

```bash
dotnet add package NKF.Domain.Tests
```

## Running Tests

```bash
dotnet test NKF.Domain.Tests.csproj
```
